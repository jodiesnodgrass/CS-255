# CS-255

Briefly summarize the DriverPass project. Who was the client? What type of system did they want you to design?

The DriverPass project was set up to assist student drivers with their DMV tests. The client was the company the project was created for Liam specifically being the owner. Liam wanted a system created that students can purchase packages, review study material if available, and set driving appointments. 

What did you do particularly well?

I believe I  did well on all my visual aids. The most detailed is the UML class diagram. That diagram shows how each class interacts with each other and was it contained in each class.

By speaking with the client and notating their ideas and requests I can identify what would be needed in the design. Without knowing what is needed there really would not be a clear idea for the project. With an unclear project the client would be unsatisfied with your work.

I approach designing software in a swift manner and not much preparation. Now seeing how helpful diagrams are I may adapt to creating a UML class diagram for future projects so I have a clear visual aid of what each class should represent.
